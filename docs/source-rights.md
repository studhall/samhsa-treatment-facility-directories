# Source Rights And Redistribution

The inspected SAMHSA directory PDFs state that report material is in the
public domain and may be reproduced or copied without permission, with source
citation appreciated. Later directories also state that the publication may
not be reproduced or distributed for a fee without written authorization.

Before creating a source-PDF release archive:

1. Run `scripts/audit_public_domain.py`.
2. Review every row with `manual_review_required=true`.
3. Exclude any PDF whose notice materially differs.
4. Publish the archive for free with checksums and citations.

The MIT license applies only to repository software. It does not attempt to
relicense SAMHSA publications or third-party geography files.

This document records the release review and is not legal advice.
